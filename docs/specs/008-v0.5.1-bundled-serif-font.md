# T3-like UsageBoard v0.5.1 规范（内置思源宋体、移除 T3 遗留、计价与限制页重构、托盘面板精修与切号）

本规范汇总并与 Henry 对齐 `v0.5.1` 的全部 11 项优化（内置字体 + 10 项细节改进），交由 GPT 按模块完整实现、测试与打包。

- **版本目标**：`0.5.1`
- **主旨**：
  1. 随包内置思源宋体可变字体（`SourceHanSerifSC-VF.otf.woff2`），消除未安装字体电脑回退 `SimSun` 的观感差异；
  2. 彻底清空所有 T3 运行时发现、历史扫描代码及「扫描 T3 账号」开关；
  3. 修正文案与计价口径：Codex `Session` 改为 `5-Hour`；`缓存读取` 统一改为 `缓存输入`；无单价模型一律按 `未定价` 处理（不再采信无法拆分的笼统上报金额），并移除费用条中的 `未拆分` 分段；
  4. 全局将 `当前` 激活账号置顶排列（托盘小面板组内第 1 位、主面板限制页最左第 1 列、账号管理同提供方组内第 1 行）；
  5. 重构主面板「限制」页：提供方标题右侧对齐展示账号胶囊栏（下方额度条内不再重复印邮箱），悬停/聚焦非当前可切换账号胶囊浮现轻提示、点击即弹二次确认切号；
  6. 精修托盘额度小面板：四列固定槽位保证百分比上下对齐、重置时间改为绝对时刻（`17:23` / `周四17:23`）、额度行悬浮单行微提示、Codex 只读展示票券数，并支持小面板行内二次确认切换账号。

## 1. 内置思源宋体可变字体（消除跨机器回退 `SimSun` 差异）

### 1.1 现状根因
- [globals.css](../../src/renderer/styles/globals.css) 目前仅声明了系统字体回退栈：
  ```css
  --font-sans: "Source Han Serif SC VF", "Source Han Serif SC", "Noto Serif CJK SC", "Songti SC", "STSong", "SimSun", Georgia, serif;
  ```
- 未手动安装思源宋体的普通 Windows 电脑会回退到 `SimSun`，导致小字号发虚、笔画粗细与字重层级失真。

### 1.2 字体获取、校验与许可合规
1. **选型**：Adobe 官方开源 **思源宋体简体中文可变字体（`SourceHanSerifSC-VF.otf.woff2`）**，采用 **SIL Open Font License 1.1（OFL-1.1）**。
2. **获取与存放**：
   - 优先从 Adobe 官方发布页 `https://github.com/adobe-fonts/source-han-serif/releases`（如 `2.003R` 的 `02_SourceHanSerif-VF.zip` 内 `Variable/WOFF2/OTF/SimplifiedChinese/SourceHanSerifSC-VF.otf.woff2`，约 `8~9 MB`）获取官方预编译 WOFF2；若网络受限，可从本机已安装的 `Source Han Serif SC VF` 原字体无损封装为 `.woff2`；
   - 存放于 `src/renderer/assets/fonts/SourceHanSerifSC-VF.otf.woff2`；
   - **严禁**对字库做破坏字重轴（`200..900`）或丢失常用汉字、拉丁字母、标点及等宽数字（`tabular-nums`）字形的有损裁剪。
3. **第三方许可声明（[THIRD_PARTY_LICENSES.md](../../THIRD_PARTY_LICENSES.md)）**：
   - 新增 `## Source Han Serif SC（思源宋体）` 章节，写明用途（内置 UI 可变衬线字体 `SourceHanSerifSC-VF.otf.woff2`）、上游仓库（`https://github.com/adobe-fonts/source-han-serif`）、Adobe 原始版权与 Reserved Font Name `Source` 声明，并**完整附上 SIL Open Font License Version 1.1 英文原文条款**。

### 1.3 `@font-face`、CSP 与渲染一致性（[globals.css](../../src/renderer/styles/globals.css)、[electron.vite.config.ts](../../electron.vite.config.ts)）
1. 在 [globals.css](../../src/renderer/styles/globals.css) 顶部声明独立内置字体族名（**不写 `local(...)`**，防止本机残缺同名字体劫持）：
   ```css
   @font-face {
     font-family: "T3UsageBoard Serif SC";
     src: url("../assets/fonts/SourceHanSerifSC-VF.otf.woff2") format("woff2");
     font-weight: 200 900;
     font-style: normal;
     font-display: block;
   }
   ```
   并将 `--font-sans` 首项更新为 `"T3UsageBoard Serif SC"`（主窗口与 `#tray` 托盘面板共用同一 `globals.css`，`font-display: block` 配合本地 `asar` 加载避免 FOUT 闪烁）。
2. 在 [electron.vite.config.ts](../../electron.vite.config.ts) 的 `renderer-content-security-policy` 插件中显式加入 `font-src 'self';`：
   ```text
   default-src 'self'; script-src 'self'; style-src 'self' 'unsafe-inline'; font-src 'self'; img-src 'self' data:; object-src 'none'; base-uri 'none'
   ```
   确保 `.woff2` 作为独立静态资产输出到 `out/renderer/assets/`（不内联成 base64）。

## 3. 文案与计价口径精修（`5-Hour`、`缓存输入`、未定价不估算与移除 `未拆分`）

### 3.1 Codex `Session` 改为 `5-Hour`
- 在 [src/main/limits/probes/codex.ts](../../src/main/limits/probes/codex.ts) `window()` 中，将 `kind === 'session'` 时的窗口 `label` 由 `'Session'` 改为 **`'5-Hour'`**（`Monthly` 与 `Weekly` 保持不变）。
- 主面板「限制」页与托盘额度小面板均直接展示 `5-Hour`，并更新相关单元测试断言。

### 3.2 `缓存读取` 统一改为 `缓存输入`
- 在 [src/renderer/usagePresentation.ts](../../src/renderer/usagePresentation.ts) `usageSegments` 中（费用与 token 两种视图）将 `'缓存读取'` 改为 **`'缓存输入'`**；
- 在 [src/renderer/components/PriceOverridesDialog.tsx](../../src/renderer/components/PriceOverridesDialog.tsx) `priceFields` 中将 `'缓存读取'` 同步改为 **`'缓存输入'`**。

### 3.3 未定价模型一律不估算费用，并移除费用条 `未拆分`
- **计价规则（[src/main/usage/pricing.ts](../../src/main/usage/pricing.ts) `priceUsage`）**：
  - 凡在 `overrides`（自定义价格）与 `table`（LiteLLM 价格表，含 `rateModel` 映射）中**均查不到单价的模型（`!rate`）**：
    - 除明确标记为 `$0` 的免费模型（`reported === 0` 时返回 `{ costUsd: 0, costSource: 'providerReported', categoryCostUsd: { input: 0, output: 0, cacheRead: 0, cacheWrite: 0 }, speedPremiumUsd: 0, cacheSavingsUsd: 0 }`）外，**一律忽略日志中的笼统 `reportedCostUsd`**，直接返回：
      ```ts
      { costUsd: 0, costSource: 'unpriced', categoryCostUsd: null, speedPremiumUsd: 0, cacheSavingsUsd: 0 }
      ```
    - 当 `rate` 存在但 `listCost <= 0` 且 `reported !== null && reported > 0` 时，同样不采信无法拆分的笼统上报金额（按 `listCost` 即 `0` 与零值四分类返回）。
  - 效果：无单价模型在「明细」表中显示 `未定价`，总费用不再混入无法拆分的估算金额。
- **移除 `未拆分` 分段（[usagePresentation.ts](../../src/renderer/usagePresentation.ts)、[UsageShareBar.tsx](../../src/renderer/components/UsageShareBar.tsx)、[usageAnalytics.css](../../src/renderer/styles/usageAnalytics.css)）**：
  - `usageSegments` 在 `cost` 与 `tokens` 两种视图下均固定返回 4 个分段：**`输入` → `缓存输入` → `缓存写入` → `输出`**；移除 `'未拆分'` 分段、`pattern: 'hatch'` 及相关废弃样式/测试。

## 6. 托盘额度小面板全面精修（对齐、绝对时刻、悬浮提示、只读票券、行内切号）

### 6.1 百分比与重置时间四列固定对齐（[TrayPanel.tsx](../../src/renderer/components/TrayPanel.tsx)、[tray-panel.css](../../src/renderer/styles/tray-panel.css)）
- 将 `.tray-quota` 改为**四列固定槽位栅格**（`font-variant-numeric: tabular-nums`）：
  1. 第 1 列：窗口短标签（如 `5-Hour`、`Weekly`、`Gemini 5h`、`Claude&GPT 周`）；
  2. 第 2 列：`minmax(0, 1fr)` 紧凑进度条轨道 + 白色匀速刻度线；
  3. 第 3 列：固定宽度右对齐百分比列（例如 `38px`，`0%`～`100%` 严格上下对齐）；
  4. 第 4 列：固定宽度右对齐重置时间列（例如 `74px`；无重置时间如 `100%` 时，**仍渲染空占位节点保留列宽**，彻底消除数字错位）。

### 6.2 重置时间改为绝对时刻规则（[trayPresentation.ts](../../src/renderer/trayPresentation.ts)）
- 新增 `trayResetTime(resetsAt: string | undefined, now: number): string | null`（按本地时区）：
  - 无 `resetsAt` 或无效：返回 `null`；
  - `Date.parse(resetsAt) <= now`：返回 `'即将重置'`；
  - 与 `now` 为**同一本地自然日**：返回 24 小时制 `HH:mm`（补零，如 `17:23`、**无 `↻` 图标**）；
  - 跨本地自然日且距离 `< 7` 天：返回 `周XHH:mm`（星期与时间之间**不加空格**，如 `周四17:23`）；
  - 距离 `>= 7` 天（如跨周月度窗口）：返回 `M/D HH:mm`（如 `12/15 17:23`）。

### 6.3 额度行悬浮单行轻量微提示（[TrayPanel.tsx](../../src/renderer/components/TrayPanel.tsx)、[tray-panel.css](../../src/renderer/styles/tray-panel.css)）
- 鼠标悬停或键盘聚焦某条额度行时，在该行紧邻上方（若靠顶部空间不足则自动翻到下方，钳制在 `360px` 面板边界内）展示**单行轻量暗色微提示**（`#0f0f0f` 底、`1px solid #272727` 边框、`pointer-events: none`）：
  - 有倒计时与匀速刻度：`还需 1 小时 34 分 · 匀速应剩 68%`；
  - 仅有倒计时无匀速周期：`还需 2 天 16 小时`（已到点为 `即将重置`）；
  - `reading.stale` 为真时末尾追加 `· 缓存`；
  - 无重置时间（如 `100%` 未开始消耗）时不弹出微提示。

### 6.4 Codex 重置券只读展示
- 小面板**不做**直接兑换重置券交互（避免误触不可撤销操作）；
- Codex 账号 `resetCredits > 0` 时，在账号标题行邮箱旁展示低调只读票券徽章（`<Ticket size={11} />{account.resetCredits}`，附说明可在主面板使用）。

### 6.5 小面板行内快捷切号（[ipc.ts](../../src/main/ipc.ts)、[trayPanel.ts](../../src/main/trayPanel.ts)、[TrayPanel.tsx](../../src/renderer/components/TrayPanel.tsx)）
1. **主进程支持与焦点保护**：
   - [src/main/ipc.ts](../../src/main/ipc.ts) 中 `usageChannels.switchAccount` 校验由 `ownWindow(event)` 放宽为 **`mainOrTray(event)`**；切号完成同步推送并刷新主窗口/托盘列表与额度；
   - [src/main/trayPanel.ts](../../src/main/trayPanel.ts) 在托盘发起切号执行期间抑制因外部 App（`Antigravity.exe` / `ChatGPT.exe`）重启抢走焦点而触发的 `blur` 自动收起，直到切号完成或失败后恢复。
2. **UI 与行内二次确认**：
   - 在小面板账号标题行右侧（原 `当前` 槽位）：非当前且可切换的 `Codex` / `Antigravity` 账号显示低调 `切换` 胶囊按钮；
